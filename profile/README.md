We build practical developer tools around the infrastructure behind modern travel distribution.

Our focus is on making hotel feeds, metasearch integrations, platform requirements and travel data easier to understand, validate and integrate.

### 🏨 Hotel Feed Validator

A CLI and Node.js SDK for validating and comparing hotel feeds across platforms including Google Hotel Center, Wego and trivago.

```bash
npx @metasearch/feed-validator validate hotels.csv --target google-hotel-center
```

[GitHub](https://github.com/metasearchcomtr/feed-validator) ·
[npm](https://www.npmjs.com/package/@metasearch/feed-validator) ·

### 🤖 metasearch MCP

A remote MCP server for hotel and travel feed validation, normalization and platform requirement comparison.

